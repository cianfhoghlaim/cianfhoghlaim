# Anam Research

**Anam** (Celtic: "Soul/Breath") - A learn-to-earn cryptocurrency for Celtic language education.

> *"Restore the Soul to the Magic"* (Anam = Mana backwards)

## Project Vision

An educational MMO game centered on the British Isles that:
- Gamifies language acquisition for Irish, Welsh, Scottish Gaelic, Manx, and English
- Implements a "Learn-to-Earn" Web3 framework with the **Tuath** token
- Preserves Celtic languages through crowdsourced transcription and federated learning
- Roots mechanics in authentic Celtic mythology (Tuatha Dé Danann, Four Treasures)

## Key Technologies

### Blockchain
- **Token**: ERC20 (Tuath) with EIP-2612 permit
- **NFTs**: Dynamic Cúchulainn avatars (ERC721)
- **Networks**: Arbitrum Sepolia, Base Sepolia
- **Payments**: x402 protocol for machine-to-machine

### Data & AI
- **Orchestration**: Dagster (asset-based workflows)
- **Ingestion**: DLT + Crawl4AI
- **Vectors**: LanceDB + ColPali embeddings
- **Knowledge Graph**: Cognee + Memgraph
- **Federated Learning**: SyftBox + Flower

### Frontend
- **Framework**: TanStack Start (React 19)
- **Agent UI**: MCP-UI for embedded quizzes
- **Auth**: Sign-In with Ethereum (SIWE)
