KEY DIRECTORIES EXPLAINED
=========================

src/routes/
  - File-based routing powered by TanStack Router
  - Files become routes automatically
  - __root.tsx is the wrapper for all routes
  - Nested folders create nested routes
  - $ in filename = catch-all route

src/components/
  - Reusable React components
  - ui/ folder follows shadcn/ui pattern
  - Each component exports variants and types

src/lib/
  - Shared utilities and configurations
  - auth*.ts files handle authentication
  - utils.ts for helper functions

src/db/
  - Database schemas and migrations
  - Uses Drizzle ORM for type safety

src/styles/
  - Global CSS and design system
  - Tailwind v4 with @theme directive


GENERATED AT RUNTIME
====================
These files will be created when you run 'pnpm dev':

node_modules/              - Dependencies
.output/                   - Production build
.vinxi/                    - TanStack Start cache
.vite/                     - Vite cache
src/routeTree.gen.ts       - Generated route tree
drizzle/                   - Database migrations (after db:push)
