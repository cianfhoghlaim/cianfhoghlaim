# `dlt_sources/api_sources/`

> `api_sources/`: the cross-corpus API sources (YouTube + Spotify + SoundCloud + GitHub + LinkedIn + ResearchGate + TG4 player + Foghlaim) — 11 .py files, 6 @dlt.source.

- `youtube_videos.py` — yt-dlp + WhisperX (reused by Foghlaim lessons)

- `github.py` / `linkedin.py` / `researchgate.py` — researcher metadata
- `tg4_player_shows.py` / `foghlaim_lessons.py` — TG4 + Foghlaim corpus (Phase C)
