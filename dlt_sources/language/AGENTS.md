- `gaois.py` + `gaois_combined.py` — Gaois Irish language resources
- `heritage.py` + `hidden_heritages.py` — Heritage data
- `local_documents_by_subject.py` + `local_education_documents.py` — local-language sources
- `logainm.py` — Logainm.ie place names
- `tearma.py` + `tearma_search.py` — Téarma.ie terminology
- `universal_dependencies.py` — UD treebanks
