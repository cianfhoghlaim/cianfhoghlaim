# `dlt_sources/commonwealth/`

> `commonwealth/`: the 6 Commonwealth jurisdictions (AU + CA + IN + NZ + NG + ZA) — 633 .py files, 292 @dlt.source.

## Quick start

- `australia/` — ACARA + state-level sources
- `canada/` — provincial + federal sources
- `india/` — CBSE + ICSE + state boards
- `new_zealand/` — NZQA + Te Marautanga o Aotearoa
- `nigeria/` — NECO + WAEC + state boards
- `south_africa/` — IEB + DBE + SACAI
- `official/` — cross-Commonwealth official sources
