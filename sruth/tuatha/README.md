## Formative Assessment MMO

Long-term project: Tuatha will be a British-Isles-wide MMO available in all celtic language with powers/gameplay/art similar to Hades but set in an ancient British Isles inspired by mythologies like the Tuatha Dé Danann and Gwydion fab Dôn and Mananán Mac Lir

References to cryptocurrency protocols like x402 are not to be considered as evidence that this would be a for-profit or economic game, currency will be earnt through completing syllabus-informed homework and similar useful tasks to help empower characters or gather items in the game.

Complete work-in-progress that requires other sruth completed first.

This will be possible thanks to the great open-source work of https://bitcraftonline.com/ and SpacetimeDB
