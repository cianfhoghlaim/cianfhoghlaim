## How to regenerate the BAML client

```bash
# From the repo root
mise run baml:generate
# Or directly:
baml-cli generate
```

The generated Python client is in `baml_client/` (gitignored). The TypeScript client is in `baml_client/typescript/`.

## How to test the BAML schemas

```bash
# All BAML tests
mise run baml:test
# Or directly:
baml-cli test
```

Each `.baml` file has its own `test` block (e.g. `test ExtractGeminiReportTest`, `test ExtractUoGArtifactTest`, `test ExtractHandwrittenEquationsTest`, `test ExtractZoteroMetadataTest`).

## How to use the BAML client from Python

```python
from baml_client import b
from baml_client.types import GeminiDeepResearchReport, ZoteroPaper

# Synchronous
result: GeminiDeepResearchReport = b.ExtractGeminiReport(
    pdf_text="...the PDF text...",
    file_name="cross_border_medical_malpractice.pdf",
)

# Asynchronous
import asyncio
result: ZoteroPaper = await b.ExtractZoteroMetadata(
    pdf_text="...the PDF text...",
    file_name="2504.02890v2.pdf",
    arxiv_id="2504.02890",
)
```

The `b.ExtractEn` BAML client alias (defined in `baml_src/clients.baml`) routes through the LiteLLM gateway. The fallback `b.ExtractEnStrong` routes through Claude Sonnet 4.
