# Type-Safe Pipeline (BAML → dlt → oRPC → MCP)

The **type-safe pipeline** is the canonical Cianfhoghlaim
architecture for end-to-end data ingestion with a single source
of truth (the BAML schema) flowing through dlt (the loader),
oRPC (the API contract), and MCP (the tool surface for agents).

## The 4 layers

```
   ┌─────────────┐
   │    BAML     │  ← schema: PrimaryLearningOutcome
   └──────┬──────┘
          │  codegen (baml generate)
          ▼
   ┌─────────────┐
   │  Pydantic   │  ← mirror: PrimaryOutcomeRow
   └──────┬──────┘
          │  dlt columns=...  (single-source-of-truth columns)
          ▼
   ┌─────────────┐
   │     dlt     │  ← @dlt.resource(primary_outcomes)
   └──────┬──────┘
          │  oRPC contract
          ▼
   ┌─────────────┐
   │    oRPC     │  ← typed query: listPrimaryOutcomes(stage: string)
   └──────┬──────┘
          │  MCP tool
          ▼
   ┌─────────────┐
   │     MCP     │  ← tool: list_primary_outcomes
   └─────────────┘
```

## Layer 3: dlt resource

```python
import dlt
from baml_client import b
from sruth.oideachais.baml_client.types import PrimaryLearningOutcome

@dlt.resource(
    name="primary_outcomes",
    write_disposition="merge",
    primary_key=["stage", "curriculum_area", "learning_outcome"],
)
def primary_outcomes(pdf_path: str):
    text = extract_pdf_text(pdf_path)
    outcomes: list[PrimaryLearningOutcome] = b.ExtractPrimaryLearningOutcomes(text)
    for o in outcomes:
        yield o.model_dump()

pipeline = dlt.pipeline(
    pipeline_name="ireland_primary",
    destination="ducklake",
    dataset_name="oideachais.education.ie",
)
load_info = pipeline.run(primary_outcomes("ncca_primary.pdf"))
```

## Layer 4: oRPC contract

```typescript
// oideachais/web/src/server/contracts/curriculum.ts
import { oc } from "@orpc/contract";
import { z } from "zod";

export const listPrimaryOutcomes = oc
  .input(z.object({ stage: z.string() }))
  .output(z.array(z.object({
    stage: z.string(),
    curriculum_area: z.string(),
    learning_outcome: z.string(),
  })));
```

```python
# oideachais/web/src/server/router.py
from sruth.oideachais.web.src.server.contracts.curriculum import listPrimaryOutcomes

@router.handle(listPrimaryOutcomes)
async def handle_list_primary_outcomes(input: dict) -> list[dict]:
    # Query the dlt-loaded DuckLake table
    return await query_primary_outcomes(stage=input["stage"])
```

## Layer 5: MCP tool

```python
# oideachais/mcp/curriculum.py
from fastmcp import FastMCP

mcp = FastMCP("oideachais-curriculum")

@mcp.tool
def list_primary_outcomes(stage: str) -> list[dict]:
    """List primary learning outcomes for a given stage."""
    return query_primary_outcomes(stage=stage)
```
