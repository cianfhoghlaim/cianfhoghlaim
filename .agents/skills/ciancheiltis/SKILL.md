## The 6-phase rule

Every phase gates the next on:

- RAGAS ≥ 0.70 bilingual-pair coverage
- ≥ 500 `(en, X)` pairs seeded into the lakehouse
- ≥ 1 DLT source per theme T1–T10 that ships bilingual content for the phase's language pair

## The 10-theme rule

Every new phase source MUST declare:

- `theme_code` = one of T1, T2, ..., T10
- `language_pair` = one of `en-cy`, `en-ga`, `en-gd`, `en-gv`, `en-fr` (Jersey/Guernsey, out of scope)
- `source_id` = `ciancheiltis.<phase>.<theme>`

## Firecrawl ground rules

Per the canonical MCP tool surface at <https://docs.firecrawl.dev/mcp-server/tools>:

- Use **`firecrawl_scrape` + `jsonOptions`** (not the deprecated `firecrawl_extract`) for structured extraction.
- Use **`firecrawl_map`** to seed URL inventories for legislation.gov.uk numeric slugs.
- Use **`firecrawl_monitor_*`** (5 endpoints) for recurring checks on legislation changes.
- Use **`firecrawl_interact`** for `gov.wales` CloudFront / WAF / CAPTCHA paths.
- Use **`firecrawl_parse`** for bilingual PDFs (Welsh / Irish / Scottish Gaelic / Manx).
- Use **`firecrawl_agent`** for autonomous multi-page discovery.

NEVER trust `metadata["language"]` — always run the content-based
`lingua_detector.detect_languages` on the first 5 KB of the body.
This is the SI 2007/1484 lesson: a Welsh-language page mislabelled
`language: "eng"`.
