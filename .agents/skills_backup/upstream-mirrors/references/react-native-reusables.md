# react-native-reusables — KCG Summary

## What It Is
React Native Reusables brings the shadcn/ui design system to React Native, providing beautifully crafted, accessible UI components built with NativeWind (Tailwind CSS for React Native). It follows the shadcn/ui philosophy of copy-paste ownership rather than npm dependency — components live in your project, not in `node_modules`.

## Why This Matters for Kings' College Galway
The `sruth/tuatha/ui` frontend uses a React Native + Babylon.js stack where NativeWind/Tailwind provides the styling layer. React Native Reusables' component library directly supplies the UI primitives (dialogs, buttons, forms, cards, navigation) for the educational MMO's chat interface, quest panels, student dashboards, and Celtic-themed UI chrome. The shadcn/ui design language also ensures consistency between the web app (`sruth/oideachais/web`) and the MMO client.
