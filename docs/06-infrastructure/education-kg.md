# Education Policy Context

This directory contains research on Celtic language education policies, enrollment statistics, teacher supply, and strategic frameworks across the British Isles.

## Overview

Celtic language education operates under different policy frameworks across jurisdictions, each with distinct targets, funding mechanisms, and challenges. Understanding this context is essential for evaluating language revitalization efforts and identifying data collection priorities.

| **Republic of Ireland** | Irish (Gaeilge) | 20-Year Strategy | Dual crisis |
| **Isle of Man** | Manx (Gaelg) | Language Strategy 2022-32 | Micro-revitalization |

| Region | Projected Decline (2025-2035) |

# Celtic Language Education Policy Frameworks

## Overview

Each jurisdiction operates under distinct legislative and policy frameworks for Celtic language education. This document compares approaches, targets, and implementation mechanisms.

---

## 1. Wales: Cymraeg 2050

### 1.1 Policy Overview

| Property | Value |
|----------|-------|
| **Strategy Name** | Cymraeg 2050: A million Welsh speakers |
| **Launch Date** | 2017 |
| **Target** | 1 million Welsh speakers by 2050 |
| **Legal Status** | Statutory framework |

### 1.2 Key Targets

| Target | Current | 2050 Goal |
|--------|---------|-----------|
| Welsh speakers | ~900,000 | 1,000,000 |
| Daily Welsh use | ~150,000 | 500,000+ |
| WM education | 21% | 40% |
| Transmission rate | ~25% | 50%+ |

### 1.3 Education Pillars

1. **Increase Welsh-medium provision**
   - 40% of pupils in WM education by 2050
   - New schools in English-speaking areas

2. **Expand workforce**
   - Welsh in Education Workforce Plan
   - Sabbatical scheme for upskilling

3. **Improve transition**
   - Foundation Phase (3-7) immersion
   - KS2-KS3 continuity

### 1.4 Implementation Mechanisms

| Mechanism | Description |
|-----------|-------------|
| **WESPs** | Welsh in Education Strategic Plans (local authority) |
| **Targets** | Statutory pupil targets per LA |
| **Categorization** | School language categorization system |
| **Funding** | Welsh-medium teaching grants |

### 1.5 Challenges

- Workforce shortage (15% secondary recruitment)
- Static 21% market share
- Urban expansion barriers
- HE drop-off (from 30% to 21% studying in Welsh)

---

## 2. Scotland: Gaelic Language Plan

### 2.1 Policy Overview

| Property | Value |
|----------|-------|
| **Framework** | Gaelic Language (Scotland) Act 2005 |
| **Body** | Bòrd na Gàidhlig |
| **Model** | Demand-led provision |
| **Legal Status** | Statutory duty to "have regard to" |

### 2.2 Key Features

1. **Demand-led model**
   - Parents request GME provision
   - Local authority must assess demand
   - No automatic right to provision

2. **National Gaelic Language Plan**
   - Updated every 5 years
   - Sets priorities for public bodies

3. **Education Scotland support**
   - Curriculum for Excellence (Gàidhlig)
   - e-Sgoil (online provision)

### 2.3 Funding Mechanisms

| Mechanism | 2025/26 Amount |
|-----------|----------------|
| **Gaelic Specific Grant** | £4.55M |
| **Highland Council allocation** | £940K |
| **Stòrlann (resources)** | ~£400K |

### 2.4 Challenges

- "Postcode lottery" of provision
- No GME in many council areas
- Secondary specialist shortage
- Community language decline
- 81% of "Gaelic learners" not in immersion

---

## 3. Northern Ireland: Identity and Language Act 2022

### 3.1 Policy Overview

| Property | Value |
|----------|-------|
| **Legislation** | Identity and Language (NI) Act 2022 |
| **Status** | Statutory duty |
| **Body** | Comhairle na Gaelscolaíochta (CnaG) |
| **Trigger** | Community-driven establishment |

### 3.2 Key Provisions

1. **Official status**
   - Irish recognized as official language
   - Irish Language Commissioner created

2. **Education duty**
   - DE NI must "encourage and facilitate" IME
   - Statutory basis for sector

3. **Cultural rights**
   - Identity rights framework
   - Ulster Scots also recognized

### 3.3 Funding Context

| Year | CnaG Budget | Change |
|------|-------------|--------|
| 2019 | ~£1.2M | Baseline |
| 2024 | ~£1.0M | -12% real terms |

### 3.4 School Establishment Process

1. Community group identifies demand
2. CnaG provides support and guidance
3. Development Proposal submitted
4. DE NI assessment
5. Minister decision
6. Provisional school opens (often in temporary accommodation)

### 3.5 Challenges

- 16/21 new schools in temporary buildings
- Capital investment backlog
- High SEN prevalence (32% vs 21% average)
- Specialist teacher shortage
- Resource gap (teacher-created materials)

## Overview

A critical shortage of qualified teachers capable of teaching through Celtic languages threatens the expansion and sustainability of language-medium education across all jurisdictions. This document analyzes the crisis and compares mitigation strategies.

| **Rep. Ireland** | Primary | Severe | 43% schools have vacancies |
| **Scotland** | Secondary | Moderate | Distance learning reliance |
| **Isle of Man** | All | Limited | Single school |

### 1.2 Root Causes

| Factor | Description |
|--------|-------------|
| **Linguistic barrier** | High proficiency requirement |
| **Pipeline failure** | ITE targets missed |
| **Resource burden** | Teachers create own materials |
| **Competition** | Other sectors offer better conditions |
| **Geography** | Rural posting challenges |
| **Retention** | Burnout and workload |

## 2. Entity Resolution Mechanisms

### 2.1 The Identity Problem

Unstructured data contains inconsistent nomenclature:

| Source A | Source B | Source C |
|----------|----------|----------|
| "Maths" | "Mathematics" | "Project Maths" |
| "LC" | "Leaving Cert" | "Leaving Certificate" |
| "H1" | "Honours 1" | "Grade H1" |

Without resolution, the graph becomes fragmented with duplicate nodes.

### 2.2 Resolution Strategy

Cognee uses LLM-based semantic reasoning to determine entity identity:

```python
# Internal resolution logic (conceptual)
async def resolve_entities(extracted_entities: list[Entity]) -> list[Entity]:
    """
    Merge semantically identical entities.
    """
    resolved = []
    seen_canonical = {}

    for entity in extracted_entities:
        # Check if semantically similar to existing entity
        for canonical, variants in seen_canonical.items():
            if llm_judge_same_entity(entity.name, canonical):
                # Merge into existing canonical entity
                variants.append(entity)
                break
        else:
            # New canonical entity
            canonical_name = llm_canonicalize_name(entity.name)
            seen_canonical[canonical_name] = [entity]
            resolved.append(Entity(name=canonical_name, type=entity.type))

    return resolved
```

### 2.3 Resolution Examples

| Raw Input | Canonical Form | Reasoning |
|-----------|----------------|-----------|
| "Maths", "Mathematics", "Math" | `Subject:Mathematics` | Same subject |
| "H1", "Honours 1", "Grade H1" | `Grade:H1` | Same grading symbol |
| "Trinity", "TCD", "Trinity College Dublin" | `University:TCD` | Same institution |
| "Physics", "Applied Physics" | Separate entities | Different subjects |

async def export_cypher_to_json(driver, query: str = None):
    """Export Cypher query result to visualization format."""
    if query is None:
        query = "MATCH (n)-[r]->(m) RETURN n, r, m"

    async with driver.session() as session:
        result = await session.run(query)

        nodes = {}
        links = []

        async for record in result:
            n = record["n"]
            m = record["m"]
            r = record["r"]

            # Add nodes
            nodes[n.id] = {
                "id": n.id,
                "label": n.get("name", str(n.id)),
                "group": list(n.labels)[0] if n.labels else "default",
                **dict(n)
            }
            nodes[m.id] = {
                "id": m.id,
                "label": m.get("name", str(m.id)),
                "group": list(m.labels)[0] if m.labels else "default",
                **dict(m)
            }

            # Add link
            links.append({
                "source": n.id,
                "target": m.id,
                "label": r.type,
                **dict(r)
            })

        return {
            "nodes": list(nodes.values()),
            "links": links
        }

    fetch(`/api/neighborhood/${initialNodeId}?depth=1`)

      links: [...prev.links, ...expansion.links.filter(

        )

# Graphiti: Temporal Knowledge Graphs for AI Agents

## Executive Summary

Graphiti, developed by Zep AI, provides a bi-temporal knowledge graph architecture designed for agentic AI systems. Unlike static knowledge bases, Graphiti tracks both when facts became true in the real world (valid time) and when the system learned about them (transaction time), enabling "time travel" queries essential for accurate reasoning.

---

## 1. The Episodic Memory Paradigm

### 1.1 Beyond Static RAG

Traditional RAG systems treat knowledge as a flat collection of vectorized chunks. Graphiti introduces a fundamentally different model:

| Paradigm | Structure | Query Capability |
|----------|-----------|-----------------|
| **Vector RAG** | Flat chunks | "Find similar text" |
| **GraphRAG** | Entity-relationship graph | "How are A and B connected?" |
| **Graphiti** | Temporal entity-relationship graph | "How were A and B connected in 2020?" |

### 1.2 The Episode as Atomic Unit

Every piece of information in Graphiti enters as an **Episode**—a discrete event with temporal context:
