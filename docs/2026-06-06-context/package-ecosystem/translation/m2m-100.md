# M2M-100 — Many-to-Many Multilingual Translation

## Overview

M2M-100 is Meta AI's many-to-many multilingual translation model supporting direct translation between any pair of 100 languages without pivoting through English. The 418M parameter variant provides efficient inference for self-hosted deployment. Unlike pivot-based systems, M2M-100 translates directly between source and target languages, preserving meaning that would be lost in two-step translation.

## Why This Matters for Kings' College Galway

Celtic language translation often suffers from the "English pivot" problem: translating Irish→English→Welsh loses Irish-specific idiom in the intermediate step. M2M-100's direct Irish→Welsh translation preserves Celtic-to-Celtic semantic relationships without English as an intermediary. While NLLB-200 covers more languages and OPUS-MT provides higher accuracy for specific pairs, M2M-100 fills the direct many-to-many niche — enabling Irish↔Welsh, Irish↔Scottish Gaelic, and other Celtic-to-Celtic translations without an English intermediate.

## Key Features

- **100 languages** — Direct translation between any pair
- **No English pivot** — Source→target directly, preserving non-English semantics
- **418M parameters** — Efficient inference, low memory footprint
- **Many-to-many** — One model for all language pairs
- **Open-source** — MIT-licensed model weights

## Integration with Our Stack

M2M-100 is served via HuggingFace passthrough as a fallback in the LiteLLM gateway's `translation` alias. The model is cached in `stedding/huggingface/hub/` (~237 MB). Used for Celtic-to-Celtic translation where pivot-based systems would lose meaning.
