# r2

## Purpose for the Cianfhoghlaim project

Cloudflare R2 is an S3-compatible object storage service with zero egress fees. This stack uses rclone to mount multiple R2 buckets as local FUSE filesystem mounts, providing POSIX-compatible access to cloud object storage.

## Why it stays in komodo/pangolin/infisical GitOps

Runs on cloud as part of the personal/utility fleet. Reproducible via the IaC bootstrap; no cianfhoghlaim project dependencies.
