# it-tools

## Purpose for the Cianfhoghlaim project

IT Tools is a collection of handy online utilities for developers and IT professionals. It provides a single-page web app with dozens of tools: JSON formatters, base64 encoders, UUID generators, JWT decoders, hash generators, regex testers, SQL formatters, and many more.
