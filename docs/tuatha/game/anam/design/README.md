## Pent-Elemental Cosmology

| Element | Celtic Term | Deity | Domain |
|---------|-------------|-------|--------|
| Spirit | Anam | Danu/Dôn | Currency, Mentorship |
| Water | Uisce/Dŵr | Manannán | Travel, Inventory |
| Fire | Tine/Tân | Brigid | Combat, Crafting |
| Earth | Talamh/Daear | Dagda/Cailleach | Territory, Seasons |
| Air | Aer/Awyr | Morrígan/Arianrhod | Magic, Governance |

## Key Mythological Figures

- **Cúchulainn** (Ireland) - Berserker archetype, Warp Spasm mechanic
- **Manannán mac Lir** (Isle of Man) - Navigator, tutorial guide
- **Brigid** (Pan-Celtic) - Smith/Healer/Poet triple goddess
- **Fionn mac Cumhaill** (Ireland/Scotland) - Fianna ranger faction
- **Arianrhod** (Wales) - Gatekeeper, certification trials
- **Robin Hood** (England) - Redistribution mechanics

## Languages Supported

1. Irish (Gaeilge)
2. Scottish Gaelic (Gàidhlig)
3. Manx (Gaelg)
4. Welsh (Cymraeg)
5. English

## World Progression

1. **Phase 1**: Isle of Man (Tutorial - Manannán's domain)
2. **Phase 2**: Ireland (Ulster/Leinster), Scotland (Argyll), Wales (Gwynedd)
3. **Phase 3**: Full British Isles with Celtic calendar events
