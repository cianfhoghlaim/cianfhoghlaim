Key Files:

1. package.json
   - Dependencies: @duckdb/node-api, ioredis, @boundaryml/baml, hono, zod, drizzle-orm
   - Scripts: dev, build, start, baml:generate

2. src/index.ts
   - Hono app with analytics and caching endpoints
   - Routes for analytics, events, users, cache management
   - Middleware: cors, logger, prettyJSON, requestId, zod-validator

3. src/duckdb/client.ts
   - DuckDB connection and query helpers
   - Extension loading (httpfs, json, parquet)
   - Initialization with sample tables

4. src/duckdb/queries.ts
   - Event statistics
   - User activity analysis
   - Time series queries
   - Cohort analysis
   - Top users

5. src/cache/redis.ts
   - Redis/Dragonfly client setup
   - Basic operations (get, set, del, mget, mset)
   - Hash operations
   - Connection management

6. src/cache/patterns.ts
   - Cache-aside (lazy loading)
   - Read-through
   - Write-through
   - Write-behind
   - Stale-while-revalidate
   - Cache stampede prevention
   - Batch operations

7. baml_src/main.baml
   - BAML schema definitions
   - LLM client configuration
   - Function definitions for query generation
   - Test cases

8. src/baml/schemas.ts
   - TypeScript types for BAML schemas
   - Schema validators
   - Schema transformers
