# rybbit

## Purpose for the Cianfhoghlaim project

Rybbit is an open-source, self-hosted web UI for managing RabbitMQ message brokers. It provides a clean alternative to the built-in RabbitMQ management plugin, with message inspection, queue management, exchange configuration, and real-time metrics.

## Why it stays in komodo/pangolin/infisical GitOps

Runs on bunchloch as part of the personal/utility fleet. Reproducible via the IaC bootstrap; no cianfhoghlaim project dependencies.
