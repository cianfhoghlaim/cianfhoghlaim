This directory contains specifications for Anam's on-chain contracts.

## Contract Overview

| Contract | Purpose | SpeedRun Challenge |
|----------|---------|-------------------|
| `TuathToken.sol` | ERC20 utility token | #2 Token Vendor |
| `CuchulainnNFT.sol` | Dynamic avatar NFT | #0 Tokenization |
| `SovereigntyStaking.sol` | Land staking | #1 Staking |

## Development Stack

- **Framework**: Scaffold-ETH 2
- **Networks**: Arbitrum Sepolia, Base Sepolia
- **Standards**: ERC20, ERC721, EIP-2612, EIP-3009
