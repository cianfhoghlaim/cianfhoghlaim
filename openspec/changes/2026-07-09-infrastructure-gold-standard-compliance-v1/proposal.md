# Change: 2026-07-09-infrastructure-gold-standard-compliance-v1

## Why

The `bonneagar/stacks/` fleet (87 stacks post-cleanup) is the
canonical GitOps source-of-truth for the 3 host topologies
(`arm1-oci` + `bunchloch` + `cax41-hetzner`). Across the v4 → v5
→ v6 refactors a structural drift has accumulated:

1. **Five placeholder stack dirs were auto-generated in 2026-07**
   by the Unstract stack sidecar (`backend/`, `platform-service/`,
   `runner/`, `workers/`, `x2text-service/`). Each contains a 1-line
   `compose.yaml` stub with `services: {}` and an empty `.env`. They
   exist *only* to satisfy the `bun run validate-stacks` GOLD_STANDARD
   gate (every stack dir needs at least one `*.yaml`); the real
   Unstract services are sub-containers in `bonneagar/stacks/unstract/`.

2. **`.env.example` coverage is only 32/87 stacks** (37%) — the
   6-file GOLD_STANDARD requires that every stack that declares a
   custom env var MUST have a `.env.example`. The remaining
   55 stacks either have no env (legitimately) or have env but
   forgot the example.

3. **`pangolin.yaml` coverage is only 23/87 stacks** (26%) — the
   6-label Pangolin route declaration is missing for ~64 stacks.
   Most of those stacks are non-web-facing (storage, sidecar
   helpers, infra-tools), so they don't all need a Pangolin route,
   but the per-stack check should be relaxed to "if web-facing".

4. **`komodo/stacks/<name>-<host>.toml` coverage is 30/87** (~35%)
   — only the 30 "key stacks" subset had hand-curated Komodo
   stack definitions. The other 57 follow-on stacks were omitted
   in the May 2026 Komodo-merge.

5. **`iac/` is a Python-/TS-mixed legacy shape** — the actual
   entry point `iac/cli.ts` exists but is not exposed at the repo
   root via `bun run iac:bootstrap`; only
   `cd bonneagar && bun run iac:bootstrap` works.

6. **Stack-doctor is soft on 4 + 5 stack failures** — the script
   exits 1 on missing `compose.yaml` / missing `blueprint.yaml` /
   no-`secrets.env`-infisical-refs / `missing-doc`, but exit 2
   (warnings) for the 6-file pattern + missing `pangolin.yaml`
   + missing `.env.example` + `image: :latest`. CI does not
   fail on these.

The drift produces confusing developer UX: the README header says
"94 stacks"; `AGENTS.md` says "88"; `validate-stacks` reports
"86"; the live dir count is 87. **The single source of truth
must be the directory count + the `stacks/INDEX.md` (replacing
the stale `HEALTH_REPORT.md`).**

The 5-deletion + the 2 generators + the iac bootstrap + the CI
flipping is the bundled fix that lets us land the v6 cleanup in
one change.

## What changes

### Spec deltas (openspec/specs/infrastructure-stacks/)

| Operation | Requirement | Why |
|:--|:--|:--|
| `ADDED`    | `Requirement: GOLD_STANDARD compliance at 90%`                | The 87-stack fleet SHALL reach ≥90% GOLD_STANDARD compliance (60+/87 with `.env.example`; 60+/87 with `pangolin.yaml`) |
| `ADDED`    | `Requirement: iac:bootstrap is the canonical entry point`    | The IaC `iac/cli.ts bootstrap` SHALL be reachable from the repo root via `bun run iac:bootstrap` |
| `ADDED`    | `Requirement: stack-doctor as CI gate`                       | `bun run stack-doctor --strict --emit-md` SHALL return exit code 0 (no criticals, no warnings) on `main` |
| `MODIFIED`  | `Requirement: Selfhosted stack inventory`                    | Each stack SHALL have a `komodo/stacks/<name>-<host>.toml` mirror (replaces the hand-curated 30-stack subset) |

### `bonneagar/stacks/` cleanups

1. **`rm -rf`** the 5 placeholder dirs (`backend/`,
   `platform-service/`, `runner/`, `workers/`,
   `x2text-service/`) — verified no importers (the 5 directories
   contain only `compose.yaml` stubs + empty `.env`).

2. **Update count references** in:
   - `AGENTS.md` (root): "94 stacks" → "87 stacks"
   - `bonneagar/stacks/README.md`: "93 stacks" → "87 stacks"
   - `bonneagar/GOLD_STANDARD.md`: "94 stacks" → "87 stacks"
   - `bonneagar/AGENTS.md`: "88 / 86 stacks" → "87 stacks"
   - `docs/stacks/README.md`: "88 stacks" → "87 stacks"
   - `openspec/specs/{dlthub-platform-integration,
     documentation, agent-platform-cluster, bonneagar-iac-merge,
     bonneagar-komodo-gitops, infrastructure-stacks-documentation,
     infrastructure-stacks}/spec.md`: "94 / 88 / 86" → "87 stacks"
   - `bonneagar/package.json`: "88-stack" → "87-stack"
   - `bonneagar/komodo/procedures/deploy-wave2-bunchloch.toml`:
     "86+7 = 93" → "87"
   - `bonneagar/deploy-runbooks/bunchloch-bootstrap.md`:
     "86-stack" → "87-stack"

### New generators at the repo root

3. **`scripts/generate-stack-env-example.ts`** — a Bun script
   that walks `bonneagar/stacks/*/secrets.env` and emits a
   `.env.example` for any stack missing one. Push 32/87 → 60+/87
   with `.env.example`. Honours the `.infisical.env` template
   shape (one `KEY=<placeholder>` per secret + a `# generated by`
   marker + the Locket + Infisical + host-tag canonical vars).

4. **`scripts/generate-stack-pangolin-yaml.ts`** — a Bun script
   that emits a 6-label `pangolin.yaml` for any web-facing stack
   missing one. Push 23/87 → 60+/87 with `pangolin.yaml`.
   Default template:
   `{name}.cianfhoghlaim.ie` → first port in compose.yaml,
   `mode: http`, `protocol: http`, `roles: [tinyauth@file]`.

### IaC bootstrap

5. **Bootstrap `iac/`** — add `iac/tsconfig.json`,
   `iac/package.json` (sub-package with `@dlthub/runtime`-style
   minimal deps), and `package.json:scripts.iac:bootstrap` at
   the repo root that wraps the existing `iac/cli.ts bootstrap`
   entry point. Update `iac/README.md` to document the 3 entry
   points (`iac:bootstrap`, `iac:plan`, `iac:deploy`).

### Komodo stack generator

6. **`scripts/generate-komodo-stacks.ts`** — a Bun script that
   walks `bonneagar/stacks/*/compose.yaml` and emits a
   `komodo/stacks/<name>-<host>.toml` from the 6-file contract.
   Generates for the **57 missing stacks** (current count:
   30 hand-curated + 57 generated = 87). The script honours:
   - **Host inference**: `services.<svc>.labels` containing
     `host:arm1-oci` / `host:bunchloch` / `host:cax41-hetzner`
     wins; otherwise defaults to `bunchloch` (the data plane).
   - **Secret refs**: every `infisical://` URI in `secrets.env`
     becomes a Komodo env var.
   - **Pangolin routes**: every entry in `pangolin.yaml` becomes
     a Komodo resource.

### CI gate

7. **Wire `bun run stack-doctor` into CI** — flip the 6-file
   pattern + missing `pangolin.yaml` + missing `.env.example`
   + `image: :latest` checks from soft warnings to hard
   errors. The new `stack-doctor --strict --emit-md` exits 1
   on any critical OR warning. Emits a per-stack markdown table
   for the GitHub Actions summary comment.

### Replace `HEALTH_REPORT.md`

8. **Replace `bonneagar/stacks/HEALTH_REPORT.md`** with a fresh
   `bonneagar/stacks/INDEX.md` generated by
   `bun run stack-doctor --emit-md`. The INDEX is the single
   source of truth — `AGENTS.md` + `README.md` both link to it.
