# 2026-07-26-biep-v3-root-namespace-rename-v1

## Why

The codebase's actual repo name is `cianfhoghlaim` (post-v7 flatten). The
`oideachais` prefix dates from the pre-v4 era when this was the Irish
Leaving-Cert-only pipeline (`oideachais-pipeline`). It is now incorrect:

- The repo root is `kings_college_galway/`, the project is `cianfhoghlaim/`
- The 8 British Isles jurisdictions span way beyond Ireland
- The BIEP v2 spec already covers Leaving Cycle + Junior Cycle +
  A-Level + GCSE — not just "Leaving Cert"
- The current `oideachais` namespace causes confusion: new contributors
  think it's Irish-specific

This change renames the root namespace `oideachais` → `cianfhoghlaim`
across the entire platform — DuckLake namespaces, LanceDB tables,
BAML schemas, Dagster asset keys, openspec specs, the web app
directory, and Python module names.
