# cianfhoghlaim-educational-mmo-v1 — Cianfhoghlaim Educational MMO (8 NCCA subjects, 2D TanStack Start MVP, hybrid x402 credential)

## Why

Cianfhoghlaim has accumulated a sprawling set of historic skill references
(`.agents/skills_backup/tuatha-mmo`, `.agents/skills_backup/tuatha-platform`,
`.agents/skills_backup/pent-elemental-cosmology`, plus 70+ older files)
that documented a **Tuatha British Isles MMO** with Babylon.js 7 +
SpacetimeDB v2 + Pent-Elemental Cosmology + Crypteolas financial token.

That product never landed in production. The user (2026-06-30) has
**explicitly** redirected the platform to a different goal:

1. **Drop the Tuath / Anam / Crypteolas theming** — those names and
   cosmological framings are out of scope for new work.
2. **Keep the technological choices** — Babylon.js, SpacetimeDB, Rust+Axum,
   CopilotKit AG-UI, BAML, Dagster, DLT, CocoIndex, FalkorDB, LanceDB,
   Cognee, Graphiti, Letta, BetterAuth, Convex, x402, SIWE, VLM/OCR
   stack, model-card-driven model selection, etc. The historic skills
   remain as **reference** in `.agents/skills_backup/` but new code
   lives under `cianfhoghlaim/` with the new theme.
3. **Focus on Ireland** — narrow the British Isles 5-framework scope
   (`NCCA / CfE / CfW / CCEA / SQA`) down to **NCCA only** for the v1
   build (Republic of Ireland Junior Cycle + Leaving Certificate).
4. **Build the educational MMO on top of the downloaded syllabus PDFs**
   already at `cianfhoghlaim/leaving_certificate/{8 subjects}/{en,ga}/`.
   No web scraping is required for v1.
5. **Per-subject quest packs** generated by BAML from NCCA learning
   outcomes + past papers + marking schemes. The game client is a
   **2D TanStack Start app** (not Babylon.js 3D) for faster MVP.
6. **Hybrid x402 educational credential** — verifiable certificate
   earned by completing homework assignments informed directly from
   the index syllabus. **Off-chain badge** in Convex + FalkorDB +
   LanceDB, **on-chain Merkle anchor** on Base L2 daily. Educational,
   not financial.

This change delivers that v1 build. It **builds on** the existing
`ncca-leaving-cert-syllabi-corpus` change (the per-subject PDF download
+ BAML `ExtractSyllabusStructure`), and **supersedes** the existing
`tuatha-platform` spec (replaced by `cianfhoghlaim-educational-mmo`).

## What

A single openspec change with 5 deliverables:

### D1. New capability spec `cianfhoghlaim-educational-mmo`

`openspec/specs/cianfhoghlaim-educational-mmo/spec.md` (NEW spec) + the
delta at `openspec/changes/cianfhoghlaim-educational-mmo-v1/specs/cianfhoghlaim-educational-mmo/spec.md`.

The new spec covers 8 Requirements:

1. **8 NCCA Subjects** — the 8 LC subjects (mathematics, applied_mathematics,
   chemistry, geography, history, english, gaeilge, computer_science)
   each have a per-subject pipeline end-to-end.
2. **Per-subject quest pack** — a `qpack_<subject>.baml` file generates
   formative quest packs keyed to NCCA learning outcomes + past paper
   questions + marking schemes. Bilingual EN + GA.
3. **8 ADK specialist agents + 1 root orchestrator** — `math_agent`,
   `appm_agent`, `chem_agent`, `geog_agent`, `hist_agent`, `engl_agent`,
   `gael_agent`, `comp_agent`, plus the existing `root_agent` updated
   to route to them. Each agent is backed by LiteLLM + BAML + Letta.
4. **Hybrid x402 educational credential** — off-chain `SkillTreeBadge`
   (Convex + FalkorDB + LanceDB) + daily Merkle root anchored on Base
   L2 via `CredAnchor.sol`. Verifiable by third parties (employers,
   universities). Educational, not financial.
5. **2D TanStack Start game client** — `cianfhoghlaim/web/apps/cianfhoghlaim-mmo/`
   at port 3080, with routes for the 8 subject realms, the student badge
   wallet, the cross-subject mastery dashboard, the teacher view, and
   the public Merkle anchor verification page.
6. **NCCA-only narrowing** — `dlt/british_isles/{sct,wls,ni,jey,iom,ggy}/`
   archives to `.archive/dlt/british_isles_other/`; only `dlt/british_isles/ie/`
   remains active. (Mechanical refactor; no functional change.)
7. **Per-subject marimo notebook** — 1 marimo notebook per subject for
   teacher view + per-subject open-in-class link.
8. **Bilingual EN + GA throughout** — every BAML output supports
   `text_en + text_ga`; every UI string is bilingual; every quest
   content string is bilingual. Gaeilge-only and English-only outputs
   are documented in the BAML function signatures.

## Risks

1. **BAML extraction cost** — running `qpack_<subject>` over 8 subjects
   ≈ 8 × ~$2 = $16 one-time. Acceptable.
2. **Marimo notebook runtime** — 8 marimo notebooks may take significant
   memory. Mitigation: marimo is single-user per notebook; recommend
   `marimo edit --headless` and 1GB heap per notebook.
3. **Convex schema migration** — adding the `badges` table is a new
   schema. Mitigation: Convex additive changes are non-breaking; no
   data migration needed.
4. **Merkle anchor gas** — Base L2 gas ≈ $0.01/anchor at typical
   prices. 1 anchor/day = $3.65/year. Acceptable.
5. **Solana / Base L2 wallet** — the platform's existing
   `OPENCODE_GO_API_KEY` / Infisical-managed wallet is reused.
6. **Cross-subject progress rollup** — Convex can do this in queries,
   but FalkorDB is faster for cross-8-subject mastery queries.
   Mitigation: Convex for player-facing read; FalkorDB for analyst queries.
7. **English vs Irish language coverage** — some NCCA PDFs may have
   only EN or only GA versions. Mitigation: the BAML functions accept
   `language: "en" | "ga"` and gracefully degrade.
8. **README §7 removal ripple** — other docs may link into §7. Mitigation:
   search-and-update after the deletion; surfaces the link rot in the
   next docs consolidation change.
