# Wire English into lc5 + resolve the 972-LOC curriculum duplicate

## Why

The British-Isles Education Pipeline (BIEP) v1 flagship ships **6 priority
Leaving Certificate subjects** (Mathematics, Chemistry, Geography, Gaeilge,
**English**, Computer Science). The `british-isles-education-pipeline`
spec already lists English as one of the 6, the filesystem has had
8 English PDFs (`LC002ALP100EV.pdf`, `LC002ALP200EV.pdf`, `LC002GLP100EV.pdf`,
`LC002GLP200EV.pdf`, `SCSEC14_English_Syllabus.pdf`,
`SCSEC14_English_Syllabus_2026-06-30.pdf`, `SC-English-Spec-ENG-INT.pdf`,
`SC-English-Spec-ENG-INT_2026-06-30.pdf`) sitting in
`leaving_certificate/english/` since the 2026-06-30 ingestion,
but the **`dlt` filesystem source hasn't ingested them yet** — English was
still missing from `LC5_SUBJECTS`.

This is the lc5/lc6 sub-batches 1.1 + 1.4 finish-line:

- **Phase 1.1 (this change, Part A)** — Add English as the 6th subject in
  the `lc5_documents` filesystem DLT source + 2 regex patterns for the
  2 English PDF kinds + 6 Dagster assets (1 ingestion + 4 BAML extraction
  + 1 cognify) + 1 cron yaml.
- **Phase 1.4 (this change, Part B)** — Resolve the 972-LOC duplicate pair:
  `dlt/british_isles/ireland/education/curriculum_source.py`
  (byte-identical 972-LOC duplicate of `curriculum.py`) +
  `exam_source_update.py` (0-byte stub).

   the 3rd element of the tuple, add the new `elif subject_dir.name == "english"`

4. **Delete the duplicate pair** — confirmed via `md5` that `curriculum_source.py`

### EN handling: en-only at root, mirrors gaeilge

The English LC directory layout in
`leaving_certificate/english/` is the same asymmetric pattern
as `gaeilge/`: PDFs live at the root, **not** under `en/`. The English
syllabus is taught and examined in English only, so:

- Gaeilge root → default `language = "ga"`
- English root → default `language = "en"`
- Chemistry / CS / geography / mathematics → walk `<subject>/{en,ga}/`

The 2 new regex patterns catch the 2 English PDF kinds not yet covered by
the existing patterns:

| Pattern | Matches | Model key |
|:--|:--|:--|
| `^LC002ALP\d{3}[EI]V\.pdf$` | `LC002ALP200EV.pdf`, `LC002ALP100EV.pdf` | `qwen3-vl-8b` (exam paper) |
| `^SC-English-Spec-ENG-INT.*\.pdf$` | `SC-English-Spec-ENG-INT.pdf`, `SC-English-Spec-ENG-INT_2026-06-30.pdf` | `gemma-4-26B-A4B` (syllabus/spec) |

(The existing `LC\d{3}[AG]LP\d{3,4}[EI]V` regex also catches the English exam
papers, but the explicit LC002ALP pattern is more bulletproof against future
LC002 syllabus updates that may add new filename variants.)
