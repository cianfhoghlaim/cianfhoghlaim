## ADDED Requirements

### Requirement: BAML Domain Templates

The system SHALL provide 18 domain-specific BAML prompt templates
at `baml_src/_shared/templates/`, one per major domain
(processing × 6, celtic × 3, ireland × 4, isles × 3, european_nations,
american_nations). Each template MUST use the canonical BAML 0.223.0
features (`_.role("user")`, `ctx.output_format`, `{% if %}` branching,
`catch_all` error handling, `@description` decorators).

#### Scenario: Template generator regenerates the 18 templates
- **WHEN** an operator runs `python scripts/baml_generate_templates.py`
- **THEN** 18 template files are written to `baml_src/_shared/templates/`
  AND the templates are valid BAML syntax (parseable by `baml-cli`)

#### Scenario: Template routes by parent directory
- **WHEN** `baml_bulk_replace_stubs.py` processes a stub function in
  `baml_src/processing/author_archive.baml`
- **THEN** the function is rewritten with the body of the
  `processing_author_archive.baml` template

### Requirement: BAML Stub-Prompt Replacement

The system SHALL replace every `"Auto-generated extraction prompt."`
stub in `baml_src/**/*.baml` with a substantive prompt body
sourced from the appropriate domain template.

#### Scenario: 478 stubs replaced
- **WHEN** `python scripts/baml_bulk_replace_stubs.py` runs
- **THEN** 478 stub functions are rewritten across 261 BAML files
  AND `python scripts/lint_baml_stub_prompts.py` reports OK

#### Scenario: Undo restores the original files
- **WHEN** `python scripts/baml_bulk_replace_stubs.py --undo` runs
- **THEN** every modified file is restored from the backup at
  `.baml_stubs_backup/`

### Requirement: BAML Catch-Block Coverage

The system SHALL add a `catch_all` block to every `Extract*`
function in `baml_src/**/*.baml` that lacks one. The catch block
MUST emit a safe-default value for the function's return type
(generated by reading the class definition's `@description`
decorators).

#### Scenario: 375 catch blocks added
- **WHEN** `python scripts/baml_bulk_add_catch.py` runs
- **THEN** 375 catch blocks are added across 254 BAML files
  AND `python scripts/lint_baml_catch_coverage.py` reports OK

#### Scenario: Undo restores the original files
- **WHEN** `python scripts/baml_bulk_add_catch.py --undo` runs
- **THEN** every modified file is restored from the backup at
  `.baml_catch_backup/`

### Requirement: BAML AGENTS.md Documented

The system SHALL document the 18-template pattern + the 2 mandatory
patterns (stub replacement + catch coverage) in `baml_src/AGENTS.md`.

#### Scenario: AGENTS.md includes the 18-template section
- **WHEN** an agent loads `baml_src/AGENTS.md`
- **THEN** the "18 domain templates" section is present AND the
  2 mandatory patterns (stub replacement + catch coverage) are
  listed with their enforcement scripts
