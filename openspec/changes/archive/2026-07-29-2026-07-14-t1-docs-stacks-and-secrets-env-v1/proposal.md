# Change: 2026-07-14-t1-docs-stacks-and-secrets-env-v1

## Why

The T1 subagent at commit `52b90f054`
(`chore(infrastructure): generate komodo stacks + INDEX for v6`) shipped
the 3 T1 v6 generators (`scripts/generate-stack-env-example.ts` +
`scripts/generate-stack-pangolin-yaml.ts` + `scripts/generate-komodo-stacks.ts`)
and drove the bulk GOLD_STANDARD compliance to 88+ / 89 stacks. T1
**deferred** the per-stack docs + the `secrets.env` infisical refactor
because they were out-of-scope for the 3-generator commit. They are
tracked by open issue **#107**.

This change ships the deferred work:

1. **The doc generator** — `scripts/generate-stack-docs.ts` (the missing
   4th generator in T1's set). Bun script that walks
   `bonneagar/stacks/<name>/`, parses `compose.yaml` + optional
   `README.md` + `blueprint.yaml` + `pangolin.yaml`, and emits the
   4-section per-stack doc that matches the hand-written baseline (see
   `docs/stacks/cal-diy.md`, `docs/stacks/litellm.md`,
   `docs/stacks/infisical.md`).

2. **9 missing `docs/stacks/<name>.md` files** — the ones T1 didn't
   generate (5 stacks with hand-written docs + 9 stacks with no docs
   yet). Closed by running the new generator with `--apply`.

3. **13 `secrets.env` refactors** — the 5 stacks whose `secrets.env`
   files contained plaintext `KEY=value` lines (komodo dev creds +
   gateway config) + the 8 placeholder files that documented infisical
   in a comment but had no `KEY=` line that the stack-doctor regex
   `(infisical://dev-baile/|\{\{ infisical://)` would accept. All 13
   are now in canonical v4 form
   (`LOCKET_MODE=watch` + `KEY=infisical://dev-baile/<stack>/<key>`
   or documented-placeholder comment).

   > **Note on the 18 vs 13 discrepancy**: open issue #107 names 18
   > stacks ("actual, browser, dozzle, enclosed, it-tools, Kapowarr,
   > komodo, LetterFeed, llama-swap, marimo, pastemax, pinchflat,
   > searxng, audiobookshelf, dragonfly, forgejo, gluetun, litellm").
   > 5 of those 18 (`browser`, `dragonfly`, `forgejo`, `gluetun`,
   > `litellm`) already comply with the v4 contract — `dragonfly`,
   > `gluetun`, `litellm` use the canonical `infisical://dev-baile/...`
   > form, `forgejo` uses the
   > `{{ infisical:///... }}` template form (accepted by
   > stack-doctor), and `browser` has no `secrets.env` (no secrets).
   > The remaining **13** files were the real refactor target.

4. **The placeholder fix generator** —
   `scripts/fix-secrets-env-placeholders.ts` — idempotent Bun script
   that converts the 8 placeholder `secrets.env` files into the
   canonical v4 format so `bun run validate-stacks` no longer warns
   "secrets.env has no infisical:// refs".

5. **2 MODIFIED spec deltas** on `infrastructure-stacks` +
   `infrastructure-stacks-documentation` to formalise both contracts.
