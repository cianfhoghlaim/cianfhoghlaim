# NCCA Leaving-Cert Syllabi Corpus — URL Inventory

**Date:** 2026-06-30
**Verified by:** Firecrawl `scrape` calls (markdown + links format) against curriculumonline.ie pages
**Methodology:** each `curriculumonline.ie/{en|ga-ie}/senior-cycle/senior-cycle-subjects/{slug}/` page was scraped; PDF links to `getmedia/...` URLs were extracted from the markdown main content.

> **Important convention discovered:** the NCCA does **not** publish separate Higher-Level and Ordinary-Level PDFs for Leaving Certificate subjects. Each syllabus is a **single PDF** that contains both HL and OL sections (and Foundation for Mathematics and Gaeilge). The PDFs in this inventory are the canonical currently-taught syllabus for each subject per language.
