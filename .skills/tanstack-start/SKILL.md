# TanStack Start Skill

## Context
When assuming the `frontend-dev` persona, use this for building the `oideachais/web_app`.

## Rules
- Adopt a "Local-First" reactive strategy.
- Utilize `@tanstack/react-router` for SSR routing and `@tanstack/db` for offline differential data syncs from DuckLake.
- Authentication is strictly handled via `better-auth`.
